# Font đi kèm

Be Vietnam Pro và Lora là hai họ font của giao diện mẫu. Các file được lưu nguyên bản từ kho Google Fonts để ứng dụng đọc trực tiếp trên máy, không yêu cầu Google Fonts qua mạng khi sử dụng.

- Be Vietnam Pro: https://github.com/google/fonts/tree/main/ofl/bevietnampro
- Lora: https://github.com/google/fonts/tree/main/ofl/lora
- Giấy phép SIL Open Font License 1.1 đi kèm: BeVietnamPro-OFL.txt và Lora-OFL.txt.

Không thay đổi hoặc cài font vào hệ điều hành. Các font chỉ được tải từ thư mục web/fonts của ứng dụng. Đã kiểm tra cmap của cả sáu file có đủ ký tự tiếng Việt dùng trong các tiêu đề và trường thông tin đã thử.
